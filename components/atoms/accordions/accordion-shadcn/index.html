Padrão

Sim, segue o padrão de design WAI-ARIA, com navegação por teclado, foco visível e estados refletidos em aria-expanded.

Sim, todas as cores, espaçamentos e tipografia vêm dos tokens --color-* e --space-*, então herdam automaticamente a marca configurada.

Sim, o painel abre e fecha com uma transição de grid-template-rows, suave e performática, sem medir alturas via JavaScript.

Bordered

Sim, usa apenas recursos padrão de HTML, CSS Grid e JavaScript vanilla, sem dependências externas.

O comportamento padrão é abertura única, mas basta remover o trecho que fecha os outros itens em script.js para permitir múltiplos abertos.
