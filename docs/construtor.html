Capítulo 03 · Ferramenta

O Construtor de Página:
monte landing pages sem escrever código

Uma ferramenta interativa embutida no Navigator que transforma a escolha de componentes em um JSON pronto para o chat do Claude montar a página completa, na ordem certa, com a marca certa.

7 passos 6 padrões de sorteio Acesso pelo botão flutuante Construtor no Navigator
3.1

Passo a passo

Clique nos itens à medida que for testando, seu progresso fica salvo neste navegador.

  1. Ative o modo construtor

    Clique no botão flutuante "Construtor de Página", no canto da tela do Navigator. O corpo da página entra em builder-mode: os cards passam a ser clicáveis para seleção em vez de links.

  2. Escolha os componentes

    Clique nos cards desejados. Cada um recebe um número de posição (1, 2, 3...) que substitui o selo de seleção: é a ordem em que a seção vai aparecer na página final.

  3. Escolha a variante de cada um

    Componentes com múltiplas variantes mostram um seletor (V1, V2, V3...). Use o preview ao vivo para decidir qual estilo combina com o projeto.

  4. Ou use o 🎲 Sortear

    Sem ideia de por onde começar? O botão Sortear gera uma estrutura completa a partir de 6 padrões pré-definidos: Landing SaaS, Agência Digital, Startup/MVP, Portfólio, E-commerce e Enterprise, sempre com header, abertura, prova social, conversão e rodapé na ordem certa.

  5. Reordene com ↑ / ↓

    A partir de duas seções selecionadas, a bandeja inferior mostra uma lista reordenável. Use as setas para mover qualquer seção para cima ou para baixo, os números de posição se atualizam sozinhos.

  6. Configure a marca

    Abra "Configurar Marca" para definir cores, fontes e textos de cada seção. Ao clicar fora do modal (ou apertar Esc), tudo é salvo automaticamente, nada se perde.

  7. Gere o JSON e leve para o Claude

    O botão "Gerar JSON →" exporta a seleção (componentes, ordem, variantes e marca). Cole esse JSON no chat do Claude Code dentro do projeto: ele vai montar a página completa usando exclusivamente os componentes já existentes no sistema.

Por que gerar JSON em vez de pedir "monte uma página" direto? O JSON registra exatamente quais componentes, variantes, ordem e tokens de marca você escolheu, o Claude monta a página fiel à sua decisão, sem inventar seções novas ou misturar estilos fora do sistema.
3.2

Checklist antes de gerar o JSON

Use esta lista como revisão final, clique para marcar cada item conforme verifica.

  • A ordem das seções faz sentido, header no topo, CTA e rodapé no fim?
  • As variantes escolhidas combinam visualmente entre si (mesma "temperatura" de design)?
  • As cores, fontes e textos da marca estão preenchidos em "Configurar Marca"?
  • A página tem header, hero, ao menos uma seção de prova social e um CTA final?
  • Você copiou o JSON gerado e está pronto para colar no chat do Claude?
3.3

Os 6 padrões do "Sortear"

Em vez de sortear componentes de forma totalmente aleatória, o que poderia gerar páginas sem lógica, o botão 🎲 Sortear escolhe entre seis arquétipos de página. Cada um define a sequência de tipos de seção; o sorteio decide apenas qual variante específica preenche cada posição.

PadrãoSequência típica
Landing SaaSHeader → Hero SaaS → Feature Cards → Stats → Depoimentos → Pricing → FAQ → Footer
Agência DigitalHeader → Hero Split → Serviços → Cases/Equipe → Depoimentos → CTA → Footer
Startup / MVPHeader → Hero Countdown → Features → Integrações → CTA → Footer simples
Portfólio / ConsultorHeader light → Hero Personal → Sobre/Feature → Depoimentos → Contato/CTA → Footer
E-commerce / ProdutoHeader → Hero Background → Carousel → Stats → Depoimentos → Pricing → Footer
Enterprise / ServiçoHeader utility → Hero Centered → Serviços → Client Band → Stats → CTA → Footer dark
Resultado garantido: qualquer combinação sorteada tem começo (header + abertura), meio (apresentação + prova social) e fim (conversão + rodapé), nunca uma página "torta".
