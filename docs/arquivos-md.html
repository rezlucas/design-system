Capítulo 05 · Convenções

Os arquivos .md,
uma linguagem comum entre humanos e IAs

Este projeto usa uma convenção de documentação estruturada para ser lida tanto por pessoas quanto por agentes de IA. Cada arquivo tem um papel único, clique em cada um para abrir os detalhes.

5 arquivos de convenção Padrões abertos agents.md e Agent Skills
5.1

A ordem de leitura importa

Qualquer agente de IA que abrir este projeto deve seguir esta sequência antes de começar a trabalhar, pois é isso que garante que humanos e IAs operem com o mesmo entendimento do estado atual.

  1. AGENTS.md

    O ponto de entrada, regras, workflow e skills disponíveis.

  2. README.md

    Visão geral técnica do projeto para humanos.

  3. CONTEXT.md

    O estado atual, o que já existe, o que está pendente, decisões tomadas.

  4. skills/README.md

    As capacidades especializadas disponíveis para a tarefa em mãos.

Regra de ouro: se algo em outro arquivo conflitar com AGENTS.md, o AGENTS.md prevalece.
5.2

Cada arquivo, em detalhe

Clique para expandir, veja para quem é, o que contém e por que existe.

Para quem

Claude Code, Codex, GitHub Copilot, Gemini CLI, ou seja, qualquer agente de IA que abrir o projeto.

O que contém

  • Ordem obrigatória de leitura antes de qualquer tarefa
  • Princípios não-negociáveis: sem frameworks, BEM obrigatório, zero hardcoding
  • Tabela de skills e quando ativá-las
  • Workflow passo a passo para criar componentes, páginas de cliente e revisar código
  • Comportamentos proibidos e o que exige confirmação antes de executar

Por que existe

Segue o padrão aberto agents.md, formato cross-agent reconhecido por qualquer ferramenta como ponto de entrada, garantindo que toda IA receba as mesmas instruções.

Para quem

Versões mais antigas do Claude Code, que procuram exclusivamente por CLAUDE.md.

O que contém

  • Apenas um redirecionamento, instrui o agente a ler AGENTS.md como ponto de entrada real.

Por que existe

Garante retrocompatibilidade sem duplicar conteúdo. Um arquivo curto, de propósito único, você está lendo a documentação que ele aponta agora mesmo.

Para quem

A IA que retoma o trabalho em uma nova sessão e qualquer humano que precise saber o estado atual rapidamente.

O que contém

  • Status geral e fase atual do projeto
  • Lista de componentes com status concluído/pendente
  • Decisões técnicas com data: escala de espaçamento, breakpoints, fonte padrão
  • Descrição do Navigator e do Construtor de Página
  • Histórico cronológico de atualizações com agente responsável

Por que existe

Sem ele, cada sessão de IA precisaria reler todo o projeto para entender o estado atual: um processo lento, caro e arriscado. Com CONTEXT.md atualizado, um único arquivo já entrega a foto completa.

Para quem

A IA, cada skill é ativada automaticamente antes de tarefas específicas.

As 4 skills do projeto

  • bem-structure: anatomia BEM, antipadrões e checklist, ativada ao escrever ou revisar CSS
  • responsive-web-design: mobile-first, Grid vs Flexbox e breakpoints, ativada ao criar layouts
  • accessibility-basics: WCAG AA, semântica, contraste e ARIA, ativada ao criar interatividade
  • landing-page-anatomy: estrutura universal de LP e tipos de oferta, ativada ao iniciar uma página

Por que existem

Seguem o padrão aberto Agent Skills: em vez de empilhar todo o conhecimento em cada prompt, as skills entram em cena sob demanda, mantendo o foco na tarefa.

Para quem

Desenvolvedores e designers humanos que trabalham diretamente no projeto.

O que contém

  • Visão geral, stack tecnológica e estrutura de pastas
  • Anatomia de um componente, com exemplos completos
  • Sistema de tokens com exemplos de código
  • Convenção BEM, padrões de responsividade e de imagens placeholder
  • Workflow completo de criação de componentes

Por que existe

É a documentação técnica principal, mais detalhada que AGENTS.md e sem as restrições de comportamento voltadas para IA. Referência ao construir, revisar ou integrar componentes.
