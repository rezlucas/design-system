01

O que é o Tegrus Design System

O Tegrus Design System é uma biblioteca de componentes de interface construída para acelerar a criação de landing pages para clientes da Tegrus. Funciona como um catálogo vivo: cada componente é um bloco visual isolado e reutilizável que pode ser combinado com outros para montar páginas completas, sem começar do zero a cada projeto.

As três premissas centrais

  • Variedade sem reinvenção. Cada tipo de seção (hero, features, FAQ, footer...) tem múltiplas variantes visuais. Em vez de criar algo do zero para cada cliente, escolhe-se a combinação certa de componentes existentes.
  • Adaptação por tokens. O que muda entre clientes são variáveis CSS, cores, fontes, espaçamentos. Os componentes em si são universais e não precisam ser reescritos.
  • Zero dependências. HTML semântico + CSS puro + JavaScript Vanilla. Nenhum framework, nenhum build step. O resultado funciona em Vercel, Webflow, HubSpot ou qualquer hospedagem estática.
Por que isso importa: um cliente novo não significa recomeçar, significa escolher entre variantes já testadas e ajustar tokens de marca. É isso que torna o sistema rápido e consistente.
