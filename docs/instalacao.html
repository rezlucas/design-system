Capítulo 06 · Mãos à obra

Coloque o projeto
na sua máquina em minutos

Não há instalação de dependências nem processo de build. Basta baixar o repositório e abrir o index.html no navegador. Escolha abaixo o caminho que combina com você.

Nenhum pré-requisito obrigatório Opcional: VS Code + Live Server Deploy automático via Vercel
6.1

Pré-requisitos

  • Um navegador moderno: Chrome, Firefox, Edge ou Safari
  • Opcional: VS Code, para editar os arquivos com conforto
  • Opcional: Git (git-scm.com), necessário apenas para enviar alterações de volta ao repositório e publicar no Vercel
6.2

Escolha como baixar e abrir

Todas as opções chegam ao mesmo lugar, a diferença é o quanto de ajuda de IA você quer logo de cara e se precisa enviar alterações de volta ao repositório.

A forma mais rápida, sem precisar instalar nenhuma ferramenta. Ideal para visualizar os componentes e criar páginas com a ajuda do Claude Code no VS Code, sem configurar o terminal.

1 · Baixe o projeto

  • Acesse github.com/rezlucas/design-system no navegador
  • Clique no botão verde Code e depois em Download ZIP
  • O arquivo design-system-master.zip vai para a sua pasta de Downloads

2 · Extraia a pasta

  • Windows: clique com o botão direito no ZIP → Extrair tudo
  • Mac: clique duas vezes no ZIP — ele extrai automaticamente

3 · Abra no VS Code e navegue

  • No VS Code: File → Open Folder → selecione a pasta design-system-master
  • Instale a extensão Live Server, clique com o botão direito no index.html e escolha Open with Live Server
  • Ou simplesmente arraste o index.html para uma janela do Chrome
Limitação: com o ZIP você visualiza e edita o projeto localmente, mas não consegue enviar alterações de volta ao repositório nem publicar no Vercel sem instalar o Git. Para publicar, veja a seção Contribuindo de volta ou use a aba Linha de comando.

Abra o terminal (PowerShell no Windows, Terminal no Mac/Linux) e execute:

terminal 
# 1. Clone o repositório
git clone https://github.com/rezlucas/design-system.git

# 2. Entre na pasta
cd design-system

# 3. Abra o navigator no navegador
#    Windows:
start index.html
#    Mac:
open index.html
#    Linux:
xdg-open index.html

Para manter atualizado

terminal, dentro da pasta do projeto 
git pull origin master

O Claude Code é o assistente de IA integrado ao terminal que já conhece todas as convenções deste projeto, você pode pedir o que precisa em português, conversando.

1 · Instale o Claude Code

terminal 
npm install -g @anthropic-ai/claude-code

Requer Node.js 18+, baixe em nodejs.org se precisar.

2 · Clone o projeto e abra com o Claude Code

terminal 
git clone https://github.com/rezlucas/design-system.git
cd design-system

# Inicie o Claude Code dentro da pasta
claude

Na primeira vez, ele vai pedir para autenticar com sua conta Anthropic, siga as instruções no terminal.

3 · O que ele já sabe ao abrir o projeto

Lê CLAUDE.md → AGENTS.md → CONTEXT.md automaticamente e passa a conhecer todos os componentes existentes, as convenções de código (BEM, tokens CSS, zero frameworks) e o histórico de decisões. Você pode simplesmente pedir:

exemplos, em português, no chat 
"Crie uma nova variante do hero-split com formulário inline"
"Adicione o componente de preços à demo do Nexio"
"Mostre quais componentes ainda estão pendentes"

Prefere não sair do editor? O Claude Code também roda direto dentro do VS Code (ou forks como Cursor e Windsurf), como uma extensão com painel próprio, sem precisar abrir um terminal separado.

1 · Instale a extensão

  • Abra a aba Extensões no VS Code (Ctrl + Shift + X)
  • Busque por "Claude Code" (publicada pela Anthropic) e clique em Install
  • Ou instale pela linha de comando, se preferir:
terminal 
code --install-extension anthropic.claude-code

2 · Abra o projeto e inicie o painel

  • Em File → Open Folder, selecione a pasta do design-system (clonada ou extraída do ZIP)
  • Abra o painel do Claude Code pelo ícone na barra lateral, ou pelo atalho Ctrl + Esc
  • Na primeira vez, ele vai pedir para autenticar com sua conta Anthropic, basta seguir o fluxo pelo navegador

3 · Use direto da interface

O painel lê CLAUDE.md → AGENTS.md → CONTEXT.md automaticamente, igual ao terminal, e mostra os arquivos editados, diffs e comandos em uma interface visual. Você pode selecionar um trecho de código no editor e perguntar sobre ele, pedir alterações ou abrir novas páginas, sempre conversando em português.

Dica: a extensão e a versão de terminal compartilham a mesma conta e o mesmo histórico de sessões, então você pode alternar entre editor e linha de comando sem perder contexto.

O Codex CLI lê AGENTS.md automaticamente ao entrar na pasta do projeto, mesmo comportamento e convenções do Claude Code.

1 · Instale o Codex CLI

terminal 
npm install -g @openai/codex

2 · Clone e inicie

terminal 
git clone https://github.com/rezlucas/design-system.git
cd design-system

# Inicie o Codex
codex

Na primeira vez, configure sua chave de API da OpenAI:

terminal 
export OPENAI_API_KEY="sua-chave-aqui"
6.3

Visualizando localmente

Por ser HTML puro, o projeto roda só de abrir o index.html, sem servidor. Mas alguns recursos (como os iframes de preview do Construtor) funcionam melhor com um servidor local:

  • VS Code, instale a extensão Live Server e clique em "Go Live"
  • Python, python -m http.server 3000 e acesse localhost:3000
  • Node.js, npx serve . e acesse localhost:3000
6.4

Contribuindo de volta

Depois de fazer alterações, suba as mudanças para o repositório. Esta seção requer o Git instalado — se você baixou o projeto via ZIP, veja git-scm.com para instalar.

terminal, dentro da pasta do projeto 
# Veja o que mudou
git status

# Adicione os arquivos modificados
git add nome-do-arquivo.html

# Crie um commit descrevendo o que foi feito
git commit -m "feat: nova variante do hero-split com formulário"

# Envie para o GitHub, o Vercel publica automaticamente
git push origin master
Deploy automático: o Vercel está conectado ao repositório e publica qualquer push na branch master em poucos segundos, sem passos extras.
